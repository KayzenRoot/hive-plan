# HP-PLAN-005 Review Checklist

Review against:
- no vendor-specific model/API dependency in frozen domain semantics;
- QualityFloor is applied before economic ranking;
- Verified Outcome Cost includes rework/defect/human cost proxies;
- HIGH_ASSURANCE cannot silently downgrade;
- cache entries are fingerprint-bound and cannot gain authority;
- provider failover remains capability/privacy/assurance compatible;
- stale cache/provider failure cases are covered by eval plan;
- living provider notes remain non-canonical;
- exact model names/prices/thresholds remain configurable;
- no production implementation is introduced.
