# HP-PLAN-010 — Costs / Performance Detailed Layout

Status: PROPOSED

## Mission
Optimize verified engineering throughput rather than merely minimize token price.

## Primary zones
- verified outcome cost headline;
- provider/model routing map;
- QualityFloor timeline;
- token/cache/cost charts;
- Rework Tax panel;
- delivery performance trends;
- local resource telemetry;
- anomaly and recommendation rail.

## Routing map
Shows eligible models/providers, selected route, capability floor, escalation/fallback and reason codes. Provider pricing/availability is time-stamped external data, never assumed timeless.

## Rework Tax
Separates initial inference cost from retries, extra Codex rounds, reviewer/auditor calls, CI retries, human intervention and rollback/recovery.

## Performance
Track idea-to-verified-merge, WO compile latency, review latency, correction rounds, agent parallelism utility and cache savings.

## Local hardware
CPU/RAM/GPU/VRAM, queues and resource pressure can be correlated with model/media/indexing workloads. ResourcePeacekeeper actions are visible.

## Recommendations
Recommendations require evidence, e.g. `route extraction tasks to T1 candidate` or `cache miss spike after source fingerprint change`. No automatic quality-floor reduction to save money.

## Voice
`onde gastamos mais?`, `qual modelo está causando rework?`, `quanto o cache economizou?`, `por que escalou para modelo forte?`.
