# HP-PLAN-010 — VoiceOrb Cinematic Specification

Status: PROPOSED

## Role
VoiceOrb is the signature conversational object of Engineering Chat. It must make voice state immediately legible and become a recognizable Hive Plan product element.

## Form
A compact layered orb with glass shell, internal signal field, subtle depth/refraction and audio-reactive geometry/wave energy. It scales from composer control to larger voice-focus mode.

## State mapping
IDLE: calm low-energy core.
REQUESTING_PERMISSION: neutral explicit permission state.
LISTENING: cyan focus with measured mic envelope.
SPEECH_DETECTED: stronger cyan/blue response.
TRANSCRIBING: blue-violet structured internal motion.
REVIEW_TRANSCRIPT: stable pending state.
SENDING: bounded directional contraction/flow.
ASSISTANT_THINKING: violet structured pulse tied to actual runtime state.
SPEAKING: audio-output envelope.
INTERRUPTED: immediate collapse to neutral/stop indication.
CONFIRMATION_REQUIRED: warning treatment + explicit text.
ERROR: danger treatment + readable reason.
DEGRADED/OFFLINE: reduced material and explicit provider state.

## Rules
No fake thinking/listening animation. The orb cannot imply microphone capture when capture is inactive. State text/icon is always available. Destructive/high-impact voice commands use a separate confirmation surface, not merely orb color.

## Audio reactivity
Use smoothed bounded amplitude/frequency features, never raw waveform data as semantic state. Avoid excessive jitter. Resource pressure reduces sample/visual update rate before affecting recognition.

## Modes
COMPACT_COMPOSER, VOICE_FOCUS, HANDS_FREE, READ_ALOUD, SAFE_STATIC.

## Privacy
Mic active indicator is unmistakable. Provider/local/cloud processing status can be inspected. Raw audio retention is off by default.

## Accessibility
Reduced motion uses state color/icon/text with minimal transitions. Screen-reader announcements expose state. Keyboard/pointer controls mirror voice controls.

## Commercial identity
VoiceOrb may become a marketing/demo signature, but runtime truth and privacy rules are invariant across future product tiers.

## Evidence
Golden state matrix, mic permission denied, provider unavailable, low confidence, barge-in, background noise, pt-BR engineering vocabulary, resource pressure and reduced-motion captures.

## STOP CONDITION
Freeze only when visual beauty, state truth, privacy, latency, interruption and accessibility are validated together.
