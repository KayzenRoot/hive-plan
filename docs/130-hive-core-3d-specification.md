# HP-PLAN-010 — Hive Core 3D Specification

Status: PROPOSED

## Role
Hive Core is Hive Plan's signature spatial visualization and future commercial demo anchor. It must be memorable without becoming a decorative loading animation.

## Visual concept
A precision-engineered suspended core formed by concentric structural rings, an inner luminous intelligence lattice and orbiting system nodes. Materials: dark anodized metal, smoked glass, selective clear glass and restrained cyan/blue/violet emissive energy.

The object should suggest computation, coordination and project topology rather than a literal beehive.

## Semantic layers
- CORE: current project/system identity;
- RINGS: major operational domains;
- NODES: GitHub, HIVE, UADS, UGAS, Agents, Review, Evidence/Checkpoint and active subsystems;
- LINKS: actual dependencies/connectivity;
- EVENT_FLOWS: recent real event propagation;
- HALOS: bounded health/risk/focus state;
- ORBITS: optional active work/task grouping.

## States
IDLE_HEALTHY, ACTIVE_DELIVERY, ACTIVE_REVIEW, BLOCKED, DEGRADED, DISCONNECTED_PARTIAL, INCIDENT, HISTORICAL, FOCUS_NODE, RESOURCE_PRESSURE, SAFE_2D.

## Cinematic entry
On first project open, optional short entry establishes depth/core then yields control quickly. It is skipped on repeat navigation, reduced motion, efficient profiles or active urgent state. No mandatory intro blocks work.

## Interaction
Hover/focus identifies node. Select focuses camera and opens semantic summary. Double/open enters relevant screen. Voice selection can focus named systems. Reset View is permanent.

## Authoring
Blender is preferred default DCC for source assets/animation because it is automatable and broadly deployable. Maya may be used when a workflow demonstrably benefits but is not a runtime/build dependency. Runtime asset is validated glTF/GLB plus compressed textures/metadata.

## Asset budget strategy
Create HERO master plus LOD tiers. Separate structural geometry from dynamic signal effects. Prefer instancing and shared materials. Texture resolution follows visible importance. Bake detail where it preserves quality at lower runtime cost.

## Rendering
R3F/Three runtime; WebGPU preferred when supported with WebGL2 fallback. TSL-first shader direction where practical. Post-processing is bounded by FrameBudget Governor.

## Quality target
Premium desktop scene should feel like a high-end engineering control system, with stable frame pacing and crisp UI compositing. Realism comes from material/light/motion coherence, not maximal polygon count.

## Evidence
Golden turntable, representative cockpit integration, all semantic states, profile comparison, load time, draw calls, triangle count, texture budget, frame-time distribution, VRAM estimate where measurable, fallback parity.

## STOP CONDITION
Hive Core cannot freeze until its visual identity, semantic state mapping, asset pipeline, LODs, fallback and performance budgets are proven together.
