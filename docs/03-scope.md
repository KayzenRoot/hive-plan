# V1 Scope

## NECESSARY
- Engineering Chat.
- Interviewer/Discovery Agent.
- Professional planning council and specialist agents.
- Canonical Source Pack and checkpoints.
- GitHub token integration with repository/project governance capabilities.
- Hive V1 memory/RAG provider integration plus embedded local-RAG fallback.
- Context Compiler and LLM cost/router/cache engine.
- Work Order Compiler for Codex.
- Execution Completion Protocol.
- GitHub/CI observer.
- Automatic Review Engine.
- Independent Audit Engine.
- Automatic safe Correction Delta generation.
- Checkpoint/Continuity Engine.
- Dark real-time command cockpit.
- Token/cost/project/review/health observability.
- Diagram and visual artifact support in planning.
- Local Docker/Compose deployment.

## IMPORTANT, architect now / implement only if V1 DoD requires
- Rich multi-provider model routing beyond the initial supported providers.
- Deep UADS/Hades V1 orchestration.
- UGAS V1 visual/asset generation integration.
- Advanced 3D cockpit assets.
- Fully automated PR merge after independent approval.

## FUTURE
- Native executor replacing or competing with Codex.
- Multi-user organizations/RBAC/SSO.
- Public SaaS hosting and billing.
- Mobile-native clients.
- Marketplace/plugins for external organizations.
- Autonomous long-running software factory spanning multiple repos without operator governance.

## OUT OF SCOPE FOR V1
- Training a proprietary foundation model.
- Building a full IDE.
- Public internet service as a requirement.
- Broad unrelated asset/media production features.

## Scope rule
Only NECESSARY items enter V1 automatically. IMPORTANT and FUTURE items require evidence that current V1 Definition of Done depends on them before implementation.
