# Project Overview

## Product
Hive Plan is a local-first AI software-engineering planning, governance, review, and control cockpit for the Hive Project ecosystem.

## Primary user
Single internal operator in V1.

## Core job
Turn conversation into professional, traceable, verifiable software planning and governance while minimizing LLM cost and reducing manual coordination between planning, Codex execution, GitHub, CI, review, and checkpoints.

## V1 outcomes
- Professional discovery and planning by specialized agents.
- Canonical project truth persisted in GitHub.
- Work Orders compiled for Codex.
- GitHub state observed automatically.
- Completion manifests trigger review without manual 'faça o review'.
- Independent review/audit based on evidence.
- Correction prompts produced automatically when safe.
- Strong project continuity through checkpoints and RAG.
- Real-time cockpit for project state, agent activity, tokens, cost, CI, risks, and progress.

## Non-goal
V1 is not an IDE and does not replace Codex as implementation executor.
